# Machine Learning Practice Notebooks

This repository contains hands-on machine learning notebooks across EDA, classical ML, deep learning, and GenAI experiments.

## Overview

The notebooks in this repo cover:

- Data preprocessing
- Exploratory data analysis (EDA)
- Supervised learning
- Time series forecasting
- Deep learning
- Retrieval-augmented generation (RAG)

## Usage

Clone the repository and open any notebook in JupyterLab, VS Code, or Google Colab.

## Projects

1. Telecom churn prediction
2. Adult dataset EDA
3. Retrieval-Augmented Generation (RAG)
4. Time series forecasting (airline passengers)
5. Fashion image classification
6. Movie recommendation system
7. Invoice insights analysis

> Some projects are under `unnamed/` because they are single-notebook projects.
